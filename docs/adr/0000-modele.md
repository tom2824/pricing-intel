## Contexte

Le problème à résoudre, les contraintes du moment, ce qui a déclenché la décision. Assez de détails pour que
quelqu'un qui arrive dans un an comprenne pourquoi la question se posait.

## Options envisagées

1. **Option A** : avantages, inconvénients, honnêtement.
2. **Option B** : idem.

## Décision

Ce qui est retenu, et pourquoi c'est le meilleur compromis dans ce contexte-là.

## Conséquences

Ce que ça coûte, ce qu'on accepte de perdre, ce qui pourra être revu, et ce qui déclencherait une révision.
